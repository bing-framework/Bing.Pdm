# PDM 版本化、结构比较、跨模型解析与高保真渲染计划

## 目标与顺序

在当前统一模型上分阶段完成：JSON 格式迁移、复制元数据、跨模型工作区、数据库结构差异报告，以及 PowerDesigner 16.7.4 视觉基准与还原。核心库保持 netstandard2.0，CLI 和测试保持 .NET 8。保留既有公开接口，增加类型和重载。

## 阶段一：JSON 版本

- 新导出的根对象添加 `SchemaVersion: 1`，无版本的历史 JSON 视为 0。原有根模型格式不加包装层。
- `PdmJsonMigrator.Migrate(Stream, TextWriter)` 在 JSON 节点层升级 0 到 1，保留未知字段及日期形态文本，不关闭输入流；未来版本、非法版本和损坏内容明确失败。
- `PdmJsonReader` 先迁移后反序列化并重建 Lookup。CLI 增加 `migrate <input.json> <output.json>`，拒绝覆盖输入。发布 v1 格式说明和 schema。
- 测试历史/当前/未来版本、重复迁移、异常输入、流生命周期和未知字段。

## 阶段二：复制元数据

- 解析根模型及递归包中的 TargetModel、Replication、SubReplication 的定义与会话 Ref；保留原始 XML ID、ObjectID、目标 URL/ID/类型、OriginalID/OriginalClassID、ReplicaObject Ref 和父子复制关系。
- FullShortcutModel 的嵌入模型保存为独立元数据描述及索引，不计入主模型业务表、视图和图形。缺失来源/副本以带来源 ID 的诊断表示，不猜测。
- 增加来源到副本、反向和子对象追溯；循环停止并报告。JSON 往返保持元数据及诊断。
- 四份真实 PDM 用作本地回归，确认主模型业务对象数量不变。

## 阶段三：跨模型工作区

- `PdmWorkspaceReader` 从显式清单读取 PDM/JSON；清单为 `WorkspaceVersion: 1` 和 `Models: [{Key, Path}]`，路径相对清单解析。重复键、重复模型 GUID、不可读取文件失败。
- 使用 `PdmObjectAddress { ModelKey, PdmId }` 限定跨模型目标。先按 TargetModel/会话指定模型解析，否则在清单中按唯一 ObjectID 查找；验证目标类型、检测 Shortcut 循环，缺失及歧义保留诊断。
- 关系、列关联、图元和 Shortcut 保留原始单模型 ID，增加限定模型的规范地址。重复解析替换本次解析诊断；`RebuildLookup()` 只重建本模型索引。
- CLI export/generate 支持 `--workspace <manifest>`。字典显示外部依赖和复制来源，不生成失效链接；实体只生成当前模型真实表。单模型 JSON 保留地址但不自行加载依赖。
- 脱敏双模型 fixture 覆盖同名 XML ID、跨包/模型引用、缺失、歧义、链与环。

## 阶段四：数据库结构比较

- `PdmModelComparer.Compare(before, after, options)` 返回 `PdmDiffResult`，不修改输入。先按唯一同类型 ObjectID 匹配，剩余按模式/包/代码路径匹配；歧义单独报告。
- 比较表、列、键、索引、外键、视图 SQL、名称与注释及列顺序。忽略审计时间、作者、诊断顺序、图形和复制追溯；SQL/文本仅统一换行。
- JSON、Markdown、HTML 报告稳定排序，标注 DBMS 和匹配歧义。CLI `diff <before> <after> <output-dir> [json,md,html]`；默认成功 0，`--fail-on-change` 有变化为 3，输入错误 1，参数错误 2。
- 测试新增/删除、唯一 GUID 重命名、名称兜底、歧义、复合键与索引顺序、视图和跨模型关系变化，以及 PDM/JSON 混用。

## 阶段五：16.7.4 图形基准和还原

- 先建立脱敏 PDM 及 PowerDesigner 16.7.4.6866 原生彩色 PNG 基准，记录图 ID、字体、DPI、缩放和导出设置；不以当前渲染图充当基准。
- 增加 PowerDesigner 样式解析与渲染选项，默认 Simplified 保持现状。覆盖字体、对齐、线型、填充、阴影、圆角、端点、表字段顺序、RTF 分段以及绘制层级。
- HTML/SVG 共用选项；输出原图、渲染图、叠加图、差异图和几何/像素统计。浏览器验证离线、缩放、链接及移动端。首版由人工确认视觉结果，不设未批准的像素阈值。

## 验收和边界

- 每阶段执行目标测试；最终运行解决方案测试、浏览器冒烟和四份真实 PDM 本地回归。远程 CI 与原生视觉人工确认分开记录。
- 真实业务 PDM 不进入仓库；公开 fixture 和视觉基准须脱敏。本轮不做模型写回、复制同步、属性继承、迁移 SQL 或跨版本像素一致性承诺。
